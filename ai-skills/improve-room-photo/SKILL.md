---
name: improve-room-photo
description: Prepare a before/after room concept from the user's original room photograph while preserving its geometry, camera perspective, openings and fixed structures.
---
Require at least one uploaded photograph. Choose one original view as the reference. Clarify desired style, budget, retained elements and allowed changes. If missing, keep all structures and services and change only decorative finishes, lighting and movable furniture.

Use prepare_room_visual with the source photo ID, a concise design brief, explicit retained elements and allowed changes. The tool saves a design in the project visual folder; the application automatically starts one bounded image edit for a paid account. No extra Generate button is needed. Only call it when the user requests a visual or an improvement concept, including a general photo-based refurbishment request. Do not create images for mere condition questions or unrelated shopping requests. Never promise an image has been generated before the operation succeeds.

Lock camera position, lens perspective, room proportions, walls, ceiling height, beams, columns, doors, windows and fixed service locations. Preserve every named retained element. Do not silently remove walls, add openings, enlarge rooms or hide structural defects. Prefer repainting, floor finishes, lighting, furniture and textiles. Keep architectural edges aligned with the source. The original photo is retained privately. The project gallery opens a slider or side-by-side comparison.

Call the result an illustrative concept, not a guarantee or construction design. Photorealistic editing can alter geometry despite instructions: require user review of doors, windows, perspective and retained features. Do not infer that pictured products are available or represent exact shopping items. For small revisions, edit the original with the revised brief rather than repeatedly editing a generated image. Never auto-retry or create variants without a user action.
