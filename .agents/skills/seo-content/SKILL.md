# Search intent and content

1. Identify the intended audience (DIY home renovator, landlord, interior designer, etc.), their job-to-be-done and primary conversion (visualization preview, materials list, plan signup).
2. Group keywords by underlying intent, not trivial geographic or synonym permutations: e.g. visualize room renovation, bathroom redesign before/after, kitchen renovation inspiration, renovation budget and materials list.
3. Map each distinct intent to one canonical destination. Check existing route content, title, H1, introductory answer, practical evidence, internal links and relevant CTA.
4. Prefer useful examples, actual process details, pricing limitations, credible authorship/contact information and realistic claims. Do not invent case studies, usage counts, reviews, testimonials, guarantees or search volume.
5. Avoid scaled thin pages, doorway pages, near-identical profession pages, or keyword stuffing. Different profession landing pages must differ substantively in workflow and proof.
6. For French/English, write genuinely localized copy; don't assume literal translation shares the same keyword intent.
7. Output: audience/intent matrix; page brief (URL, primary question, H1/title/meta, sections, links, CTA, evidence required); prioritized backlog; checks to run in Search Console after publication.
8. Tie advice to conversion quality as well as traffic; avoid promising rankings.
