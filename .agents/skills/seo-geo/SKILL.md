# AI search / GEO

1. Verify that public pages are accessible, crawlable, understandable and canonical; AI-search visibility depends heavily on the same fundamentals as web search.
2. Check whether each important page answers real user questions directly, contains unambiguous entity/product descriptions, specific features and documented limitations, and cites any external factual claims.
3. Encourage self-contained explanations, clear headings, meaningful comparisons, first-party examples, semantic links and transparent provenance.
4. Check robots directives and important bots only against current official guidance. `llms.txt` is optional and is not proven to boost ranking or citations; never represent it as a Google requirement.
5. Separate verifiable AI referrals/citations (if supplied) from speculation. Do not manufacture AI Overview visibility or score it as objectively measured.
6. Provide a practical experiment: baseline indexed pages / referral signals; publish a small number of genuinely useful answer pages; verify accessibility and monitor Search Console and referral patterns over time.
7. No AI-bot bypass of auth, secrets, unpublished pages or site policies.
