---
name: assess-room
description: Infer a provisional room layout from uploaded photos, discuss dimensions and openings, and assess visible finishes.
---
Start with the uploaded photographs. When asked for a plan, create_room_plan in the first reply whenever enough of the room is visible; do not require measurements before making a useful first draft. Estimate floor proportions, wall lengths, ceiling height, visible door/window positions and sizes, and fixed fixtures using perspective, repeated tiles and familiar objects as tentative scale references. Cross-check all supplied views and user measurements. A photograph cannot establish true scale: explicitly label each inferred size and opening position approximate, with a plausible range and the visual evidence in assumptions. User measurements override estimates. Do not present a generic rectangle disconnected from the photos.

Use a consistent top-down orientation. Describe which photographed wall corresponds to each indexed wall; note unseen walls and uncertain orientation. Include visible openings, even when their dimensions must be estimated. Omit only objects that are not visible or reliably described; never insert an unseen door/window. Estimate irregular outlines only when visible geometry supports them. Use concise fixture labels (e.g. Shower, Vanity); place explanations in assumptions, not inside the diagram. Save provisional geometry and ask one or two targeted questions to refine the most uncertain measurement, preferably a wall length or tile size. If photos genuinely provide no usable geometry, explain what is missing and request another view. Never mark photo estimates confirmed.

Assess visible floor, walls, ceiling and joinery in natural prose: material, wear, evidence, confidence and retain/repair/replace recommendation. Do not diagnose paint chemistry, moisture, asbestos or hidden substrate integrity from photographs. Put detailed condition records in surfaces; keep the conversational summary short. Update the existing plan when the user corrects it. The application calculates area/perimeter and draws the 2D plan; never use image generation or ASCII for plans. This is a planning drawing, not a construction survey.
