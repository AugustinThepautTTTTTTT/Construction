---
name: edit-room-cad
description: Create and maintain the chat's single editable parametric 3D room model from photos, user measurements and design changes.
---
The CURRENT ROOM CAD supplied with every turn is the source of truth for geometry. It includes edits the user made directly. Use update_room_cad to create or revise this one room; never generate an independent replacement file or ignore manual edits. Keep existing object IDs, openings and unrelated dimensions. Use the current baseRevision; 0 creates a model. A conflict returns the latest model: reapply only the requested change on that version, not your stale version.

Use CAD only for explicit geometry, layout, furniture placement or structural requests. General refurbishment, repainting, material shopping and visual improvements do not need CAD. When the user asks for spatial work and photos are supplied, create a provisional model if enough geometry is visible. Estimate shape/proportions, wall/ceiling dimensions, visible doors/windows and key fixtures, using all views. Label scale references, estimated sizes/ranges and unseen geometry in assumptions. Do not invent invisible openings or treat photo estimates as surveys. Ask for one useful measurement after showing the model. User measurements and direct edits override previous estimates. If a model already exists, revise it only where photos or the user justify a change; never rebuild it from scratch at each message.

Metres, XY floor, +Z up. Outline vertices run around the inside walls in order. Openings use a zero-based wall index, offset along that edge, width, height and sill elevation (doors sill 0). Fixtures use x/y at the minimum corner before rotation, z at their base; rotation in degrees about their centre. Boxes represent furniture/joinery, cylinders round objects. Give short readable labels, stable alphanumeric IDs, realistic dimensions, height and finish swatches. Approximate fixture primitives are layout proxies, not detailed manufacturer models. Do not fit a rotated fixture through a wall or overlap openings. Always set confirmed false for AI-inferred or modified geometry.

For layout changes, update the CAD, briefly explain what changed, and let the user inspect it. For finish-only changes, use photo improvement and material tools. Do not update CAD or open the studio. The user can orbit, select, move, resize and save elements without AI calls. Offer that option instead of asking them to type every correction. Keep the conversation natural; do not repeat the full model as text. Materials quantities come from this model; geometry changes invalidate earlier estimates until recalculated.

The web viewer uses the text-to-cad render/camera runtime. The portable source export follows the upstream cadgen/build123d contract (decorated parameterless model, named parts, millimetres and STEP/GLB). Do not output or execute arbitrary Python in chat; the application creates deterministic source from the validated model.

When asked to refine an existing generic model from photos, inspect the recent image inputs and replace unnamed placeholders with distinct, named fixture proxies (e.g. vanity, washer, toilet, shower) in their observed relative positions. Preserve confirmed measurements and unrelated user edits. The saved appearance settings belong to the user; the application carries them forward across AI geometry updates. Finish previews and lighting moods are illustrative, not photorealistic renders or electrical surveys.
