---
name: improve-room-photo
description: Prepare a before/after room concept from the user's original room photograph while preserving its geometry, camera perspective, openings and fixed structures.
---
Require at least one uploaded photograph. Choose one original view as the reference. Clarify desired style, budget, retained elements and allowed changes. If missing, keep all structures and services and change only decorative finishes, lighting and movable furniture.

Use prepare_room_visual with the source photo ID, a concise design brief, explicit retained elements and allowed changes. The tool saves a design, and the application automatically starts one bounded image edit for a signed-in account with enough credits. The finished image appears directly below your reply in chat and is collected in the project visual folder. Never ask for a second confirmation or tell the user to click Generate after they have requested a concept. Introduce the result naturally in one concise paragraph, rather than treating it as a separate project task. Only call it when the user requests a visual or an improvement concept, including a general photo-based refurbishment request. Judge the CURRENT message only. Existing photos or a prior concept are references, never continuing permission to create images. A request for a bill of materials, quantities, a shopping list, working steps or construction instructions must use the saved design to create those deliverables, without calling prepare_room_visual. Only include an image when the same request also explicitly asks for a visual. Do not create images for condition questions, product searches, confirmations of a bill, or unrelated shopping requests. Never promise an image has been generated before the operation succeeds.

Lock camera position, lens perspective, room proportions, walls, ceiling height, beams, columns, doors, windows and fixed service locations. Preserve every named retained element. Do not silently remove walls, add openings, enlarge rooms or hide structural defects. Prefer repainting, floor finishes, lighting, furniture and textiles. Keep architectural edges aligned with the source. The original photo is retained privately. In chat, See before flips the image to the original and Compare animates a side-by-side view, without another AI call. The project gallery retains both views.

Call the result an illustrative concept, not a guarantee or construction design. Photorealistic editing can alter geometry despite instructions: require user review of doors, windows, perspective and retained features. Do not infer that pictured products are available or represent exact shopping items. For small revisions, edit the original with the revised brief rather than repeatedly editing a generated image. Never auto-retry or create variants without a user action.
